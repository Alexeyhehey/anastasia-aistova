# Портфолио Анастасии Аистовой

Статический сайт-портфолио фотографа: главная, серии, карта мест, контакты. Без сборки — обычные HTML, CSS и JS.

- Основной сайт — корень репозитория, публикуется через GitHub Pages из ветки `main`.
- Бета — папка `beta/` (свои копии кода, фотографии общие из `img/`).

## Запуск

```
npm install
npx vite --host 127.0.0.1 --port 4173
```

Сайт откроется на http://127.0.0.1:4173, бета — на http://127.0.0.1:4173/beta/.

## Проверки

```
npm test
npx playwright test
```

## Правила

- После правки файла поднять его номер версии `?v=` в `index.html` (и в `beta/index.html` для беты), иначе браузеры покажут старую копию.
- Размеры кадров лежат в `img/dims.js`; при замене фотографии обновить запись.
- Публикация — пуш в `main`.
