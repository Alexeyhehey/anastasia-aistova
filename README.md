# Портфолио Анастасии Аистовой

Статический сайт-портфолио фотографа: главная, серии, карта мест, контакты. Без сборки — обычные HTML, CSS и JS.

- Основной сайт — корень репозитория, публикуется через GitHub Pages из ветки `main`.
- Бета — папка `beta/` (свои копии кода, фотографии общие из `img/`).

## Студия для заказчицы

Страница `add-series.html` (у беты — `beta/add-series.html`) — студия прямо на сайте: работает с телефона, планшета и компьютера, ничего ставить не нужно.

- «Съёмки»: добавить серию с фотографиями и точкой на карте, поменять порядок, снять с сайта, удалить.
- «Тексты»: все надписи, контакты, ссылки, услуги и цены.
- «Мои фото»: кадры первого экрана и раздела «Обо мне».

Вход — по ключу GitHub. Перед первым входом заказчица входит в свой GitHub и принимает приглашение в репозиторий сайта. Затем она создаёт ключ: Settings → Developer settings → Fine-grained tokens, при необходимости Resource owner → `Alexeyhehey`, только репозиторий `anastasia-aistova`, разрешение Contents → Read and write. Можно дать готовую ссылку вида `…/add-series.html#key=<ключ>`: ключ запомнится на её устройстве. Каждое сохранение студии — коммит в `main` (у беты с пометкой `[beta]`), сайт обновляется через минуту-две.

Вёрстка терпит любые тексты: крупные надписи сами уменьшаются, если не помещаются (`helpers.js`), а карта при большом числе точек уплотняет подписи и выносит лишние в список под картой (`extras.js`).

## Запуск

```
npm install
npx vite --host 127.0.0.1 --port 4173
```

Сайт откроется на http://127.0.0.1:4173, бета — на http://127.0.0.1:4173/beta/.

## Проверки

```
npm test
npx playwright test
```

В тестах студии GitHub заменён заглушкой: в настоящий репозиторий они ничего не пишут. `tests/layout.spec.js` проверяет длинные названия и много точек на карте на трёх ширинах экрана.

## Правила

- После правки файла поднять его номер версии `?v=` в `index.html` (и в `beta/index.html` для беты), иначе браузеры покажут старую копию.
- Размеры кадров лежат в `img/dims.js`; при замене фотографии обновить запись.
- Публикация — пуш в `main`.
