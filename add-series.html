Вход в студию

Здесь вы сами управляете сайтом: съёмки и точки на карте, тексты, контакты и свои фотографии. Работает с телефона, планшета и компьютера.

Где взять ключ

Перед первым входом войдите в свой GitHub и примите приглашение в репозиторий сайта. Затем создайте ключ: Settings → Developer settings → Fine-grained tokens → Generate new token. Если GitHub спросит Resource owner, выберите Alexeyhehey. Выберите Only select repositories → anastasia-aistova и разрешение Contents → Read and write. Готовый ключ вставьте в поле выше — на своём устройстве вводить его снова не придётся.

Создать ключ в GitHub ↗

Не пересылайте ключ посторонним: с ним можно менять сайт. На чужом устройстве снимите галочку «Запомнить».

Съёмки

Каждая съёмка — это серия фотографий и точка на карте. Порядок здесь = порядок на сайте.

Новая съёмка

Точка на карте

Найдите место по названию или нажмите на карту. Точку можно поправить в любой момент.

Фотографии

Стрелками меняйте порядок. «Обложка» открывает серию, «В подборку» показывает кадр ещё и на главной. Большие файлы студия уменьшит сама.

Тексты и контакты

Откройте нужный раздел, поправьте текст и нажмите «Сохранить тексты». Заголовки на сайте сами уменьшатся, если не поместятся.
