Съёмки

В Windows откройте студию и войдите через GitHub. При следующих запусках вход сохранится.

Скачать студию для Windows

Распакуйте ZIP и откройте «Студия.exe». Для публикации нужен аккаунт с доступом на запись к сайту.

Открыть редактор в этом браузере

Владелец репозитория может войти с ключом GitHub. При создании выберите Only select repositories → anastasia-aistova и доступ Contents → Read and write. Ключ действует в этой вкладке до её закрытия.
